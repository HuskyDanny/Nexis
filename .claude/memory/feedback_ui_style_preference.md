name: UI Style Preference
description: User prefers premium dark glassmorphism aesthetic over plain/default dark themes
type: feedback
---

User prefers premium dark UI with glassmorphism, space/starfield backgrounds, subtle glow accents, and refined typography (tracking, uppercase labels). Called the default React dark theme "lame" and referenced the OpenClaw website as the target aesthetic.

**Why:** Default dark themes feel generic and unpolished. The user wants a visually premium, distinctive look.

**How to apply:** When building or modifying frontend components, use: deep dark backgrounds (#080b14 range), glass cards with backdrop-filter blur, subtle colored borders/glows per semantic meaning, uppercase tracking labels, pill badges, and animated edges. Avoid plain solid-color cards or default framework styling.
